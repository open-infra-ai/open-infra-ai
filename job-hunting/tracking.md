## 每周节奏检查清单（每周五执行）

- [ ] **投递量**：本周新投递 ≥ **8 家**？低则查原因（渠道不够 → 扩大官网直投；简历回复率低 → 回头改 `resume.zh.md`）。
- [ ] **状态更新**：所有在走流程的岗位状态 + 下一步写进上表（不留"记在脑里"的岗位）。
- [ ] **面试复盘**：本周每场面试后是否 24h 内完成复盘（写到该行备注列：被追问卡住的题 / 讲砸的 story / 下一场要主动带的证据号）。
- [ ] **证据包**：复盘发现的薄弱点是否已同步到 `interview/` 对应训练项（只读档案 → 在备注里记建议，不改档案）。
- [ ] **渠道多样性**：本周是否同时覆盖了 ≥2 个渠道（BOSS + 官网直投算 2，内推算 3）。

**周守则**：连续两周 ≤8 投递 → 停止投递半天，改简历 + 换渠道，而不是加量硬投。

## 渠道说明

| 渠道 | 用法 | 备注 |
|------|------|------|
| **BOSS 直聘** | 主渠道。主动打招呼文案复用简历定位段；先投「高匹配」公司 | 回复率最高的国内渠道，优先维护 |
| **vLLM 社区内推** | **上游 PR 是硬通货**：在 vLLM/SGLang repo 里从 good-first-issue 入手提 1-2 个真实 PR（paged-infer 的调度/契约经验可直接复用），PR 合入后在社区 Discord / 贡献者列表里找公司内推 | 长期投资：3-4 周才见效，但一次 PR 顶 10 次海投；大模型公司（硅基流动 / 字节 AML / 智谱等）都盯 vLLM 生态 |
| **脉脉** | 找目标公司「AI Infra / 推理」关键词的同事发私信，附 GitHub 链接 | 回复率中等，先发再聊；注意平台规范 |
| **LinkedIn** | 外企 / NVIDIA 中国 / 部分大厂海外岗 | 国内主渠道之外的第二选择 |
| **猎头** | 只对接 1-2 个熟悉的 AI Infra 猎头，把画像说清楚（Serving 方向，非训练） | 防止猎头推错岗位浪费时间 |
